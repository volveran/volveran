Read before changing code:

- `CONTRIBUTING.md`: commands, test suites, releases.
- `GLOSSARY.md`: the word for each concept, in code, prose and messages.
- `CODING_STANDARDS.md`: atomic store changes, fixes found in passing, what "no change in behaviour" means.
- `docs/adr/`: why things are as they are; read the ADR for the area you touch.
- `docs/agents/issue-tracker.md`: specs, tickets and labels.

Before calling work done: `npm run verify`.
